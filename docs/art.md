# Meowdoku · 美术规范

## 方向（v0.3.2 起对齐参考图）

参照玩家提供的参考图（`IMG_0668.PNG`）：暖奶油底 + **鲜亮糖果色圆角瓷砖**（瓷砖间留缝、不画格线/边界，区域靠底色区分）+ 柔和白色圆角药丸控件（无硬边框、轻投影）+ 珊瑚强调色。整体可爱、清爽、手机竖屏友好。第一视觉重点是**颜色区域瓷砖**和**小猫**。

## 区域配色（见 `data/constants.js` REGION_COLORS）

10 个鲜亮可区分的糖果色（比旧版更饱和、更接近参考图），索引 0..9 对应颜色区域：

珊瑚 `#ec9389` · 蜜桃 `#f2b98a` · 芥末金 `#e3a92f` · 奶黄 `#f2dd92` · 嫩绿 `#a8d488` · 薄荷 `#74cbb6` · 天蓝 `#54b8d6` · 薰衣草 `#bfa2dc` · 樱粉 `#e896c0` · 焦糖 `#bf9069`

> 色相均匀铺开、明度有别，N=10 相邻区域也能分清。区域**不画边界**，靠瓷砖底色 + 瓷砖间缝隙区分（仿参考图）。

## 棋盘（圆角瓷砖）

- 逻辑 `900×900` 固定，`CELL = 900 / N`，N 越大格越小，总尺寸不变。
- 每格画成一块**圆角瓷砖**（内缩 `tileGap`、圆角 `tileRadius`），瓷砖之间的缝隙露出奶油底色。
- **不画格线、不画区域边界、不画外框**——区域完全靠瓷砖底色区分（`render/grid.js`，几何走 `render/shape.js`）。

## 小猫（`drawCat`，坐姿奶牛猫 / tuxedo）

- 程序化绘制：深色身体 + 头 + 双耳（粉内耳）+ 尾巴；**白脸 + 白胸**；白脸上两只深色眼 + 粉鼻。呼应参考图的黑白猫图标。
- 主体深色**不随区域色变**——猫坐在彩色瓷砖上，深色 + 白脸在任何糖果色上都清楚。
- 冲突时换红色配色（`CONFLICT_PAL`，校验放子下基本不触发）。
- 随瓷砖等比缩放，N=10 小格也保持可识别。

## 标记与高亮

- 排除标记 ✕：暖灰、细，弱于小猫。手动 ✕ 与**自动排除 ✕** 同样式（放对猫后其行/列/九宫格/同色区域自动 ✕）；自动排除可由工具栏「自动叉」开/关。
- **放错红 ✕**：放错猫的格留下持久的**红色 ✕**（`CELL.WRONG`，`THEME.markWrong`，略粗醒目），提示此处试过且错了；再点清除。
- 选中格：柔和深紫圆角描边（不填色，不盖区域色）。
- 放错瞬间：红圆角瓷砖闪烁 + 红 ✗（`effects.flashWrong`）快速淡出，叠加上面的持久红 ✕。

## 动效优先级

1. 通关：猫爪雨 + 弹层 + 吉祥物「安家成功喵」。
2. 放对 / 提示放猫：珊瑚色脉冲环。
3. 放错：红圆角瓷砖闪 + 红 ✗ + 吉祥物气泡（剩余 ❤️）。
4. 选格 / 高亮：即时无延迟。

## UI（仿参考图）

- 竖屏单列：标题+HUD → 尺寸选择(5×5~10×10) → **规则药丸 ×3**（一种颜色一只猫 / 同行同列各一只 / 猫咪不能相邻，淡紫灰底）→ 棋盘 → 吉祥物 → 操作提示一行 → 工具(自动叉/撤销/清空/提示/新关)。
- 控件统一：白色圆角药丸 + 轻投影、无硬边框；选中 / 激活态用珊瑚色填充白字。
- 触控目标 ≥ 40px，`max-width: 480px` 居中，适配手机竖屏。
- 吉祥物 🐱 + 气泡承担情绪反馈，不写长段说明。
