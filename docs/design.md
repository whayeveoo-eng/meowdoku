# Meowdoku · 策划文档

## 一句话概念

竖屏手机上的喵主题逻辑解谜（猫版 LinkedIn「Queens」）：N×N 棋盘被分成 N 个连通的同色区域，给每只猫安一个家——**每行、每列、每种颜色恰好 1 只猫，且任意两只猫不能挨着（含斜角）**。每关有且仅有一个解。

## 玩法规则（用户定义）

1. 棋盘为 N×N，N ∈ {5,6,7,8,9,10}。
2. 棋盘总长宽固定，单元格大小随 N 动态适配（`CELL = BOARD_PX / N`）。
3. 每关棋盘格子带颜色，颜色数量 = N。
4. 每种颜色恰好一只小猫。
5. 同行 / 同列只能存在 1 只小猫。
6. 小猫周围的九宫格范围内不能有其他小猫（国王步邻接，含对角）。
7. 同色块数量不固定（最小为 1），但同色必定四连通（至少一条边相邻）。
8. 初始没有小猫，由玩家放置。
9. 关卡“透明”：根据颜色块布局 + 规则可**从初始盘面一步步严格推导出唯一解**（不靠猜）。

> 这正是 LinkedIn「Queens」的规则集（猫 = 皇后；约束是「不相邻」而非整条对角线）。N<5 无可行布局，故从 5 起。

### 唯一解 vs 无需猜（重要区别）

“唯一解”只保证答案唯一，**不**保证人能纯逻辑推出来——有些唯一解关卡仍需试探 / 回溯。本作用一个**人类式逻辑求解器**（见 tech.md）做生成过滤，只保留“能一步步推出来”的关卡。这是血量惩罚公平的前提：既然不需要猜，扣血就只因真正的失误。

## 为什么不是数独 / 不是小球碰撞

- 不是数独：没有数字、没有 3×3 宫、约束完全不同。
- 不是小球碰撞观赏游戏：这是玩家操作的逻辑解谜，不用 HP / 伤害 / 节奏交锋。
- 但**复用项目通用工程约定**：独立文件夹、`docs/` 文档骨架、模块化 `src/`、可种子 RNG、`window.__game` 式测试钩子、根 README 登记。

## 第一版范围（v0.3.0）

- 六档棋盘尺寸 5×5 ~ 10×10，棋盘总尺寸固定、格子自适应。
- 生成保证**唯一解且纯逻辑可解（无需猜）**的关卡（合法布局 → 区域生长 → 唯一性精修 → 逻辑求解器过滤）。
- **血量**：每关 3 ❤️。放错猫扣 1 滴，归零失败（可同 seed 重来或换关）。
- **校验放子**：放猫前校验是否为唯一解的正确格——正确才落子；错误扣血、不落子，并在该格**留下持久红 ✕** 提示（再点可清除），同时红闪一下。
- 交互：**点击循环三态**（空 → ✕ 排除标记 → 🐱 → 空）；键盘方向键移动 + 空格循环 + Z 撤销。
- 辅助：撤销、清空、提示放一只正确的猫。
- **自动排除（auto-X，可开关）**：放下一只正确的猫，自动给它的整行 / 整列 / 九宫格 / **同色区域其它格**打 ✕（移走猫则撤回）；已被自动排除的格不允许尝试放猫（点它只在 空↔✕ 切换，不误扣血）。工具栏「自动叉」按钮可开/关，偏好持久化保存；关闭后只剩手动 ✕。
- 反馈：放对猫的爪印脉冲、通关猫爪雨 + 弹层、猫咪吉祥物气泡。
- HUD：用时、已放猫数 / N、当前冲突数。

## 暂不实现（避免膨胀）

- 每日一题、连胜、成就、排行榜、存档（可种子 RNG 已为每日题预留）。
- 音效 / BGM（已留 `assets/audio/` 与事件钩子）。
- 皮肤 / 主题猫角色（v3 美术，先用 emoji + 剪影占位）。

## 棋盘与规则参数

| 项 | 值 |
| --- | --- |
| 棋盘 | N×N，N ∈ {5,6,7,8,9,10}，默认 8 |
| 逻辑画布 | `900 × 900`（固定），`CELL = 900 / N` |
| 颜色区域数 | = N，每区四连通、含 1 只解中猫 |
| 血量 | 每关 3 ❤️，放错猫 -1，归零失败 |
| 胜负 | 放满 N 只正确猫 → 通关；血量归零 → 失败 |
| 关卡保证 | 唯一解 **且** 纯逻辑可解（无需猜） |

## 难度感觉（参考）

N 越大越难（行 / 列 / 颜色更多，推理链更长）。无需猜生成耗时实测（180 关样本均值）：

| N | 5 | 6 | 7 | 8 | 9 | 10 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 生成均值 | `<1ms` | `<1ms` | `~1ms` | `~6ms` | `~19ms` | `~109ms` |

## 可扩展项（后续配置入口）

- 主题皮肤 / 猫角色：`data/constants.js` 的 `REGION_COLORS` 与 `cells.js` 的 `drawCat`。
- 每日一题：固定 seed = 日期，`newGame(N, seed)` 复现。
- 计分：用时 + 提示 + 冲突修正次数，数据已在 `stats` 中。
- 变体：更大 N、星阵（每区/行/列 2 只）等，约束写进 `solver` 即可。
