# Meowdoku · 测试文档

## 生成器自动测试（核心正确性）

```bash
node tools/smoke.mjs 40     # 每个尺寸 5..10 各 40 关，共 240 关
```

每关校验：

1. **区域合法**：恰好 N 个颜色区，各非空且四连通；颜色数 = N。
2. **唯一解**：`countSolutions(region, N, 2) === 1`。
3. **solution 满足全部规则**：N 只猫、自身零冲突、行/列/色各覆盖一遍、任意两只不相邻。
4. **求解结果 === solution**（集合相等）。
5. **纯逻辑可解（无需猜）**：`logicalSolve(region, N)` 能完全解出且 === solution。
6. **零 fallback**：每关都真正找到了“逻辑可解”关卡。

同时输出每尺寸的生成耗时（avg / max）与尝试次数。

> 改 `solver.js` / `generator.js` / `board.js` 后必跑。基线（180 关）：5–7 `<4ms`，8 `~6ms`，9 `~19ms`，10 均值 `~109ms`（max 偶发 ~840ms），零 fallback。

## 功能冒烟（浏览器）

每次改动后至少确认：

- 页面打开无控制台报错。
- 棋盘按 N 上色、统一细格线、外框清楚。
- 点击格子三态循环：空 → ✕ → 🐱 → 空。
- **校验放子**：放正确格 → 落子 + 脉冲，HP 不变；放错误格 → 红 ✗ 闪烁、扣 1 ❤️、不落子。
- **血量**：HUD ❤️/🤍 正确；3 次放错 → 失败弹层；“再试一次”同 seed 恢复 3 ❤️。
- **自动排除保护**：点已自动 ✕ 的格只在 空↔✕ 切换，不扣血、不放猫。
- 撤销逐步可逆（错误尝试不计入撤销、不退血）；清空清掉所有标记；提示放下一只正确猫。
- 放满 N 只正确猫 → 通关：爪雨 + 弹层 + 用时正确。
- 切尺寸 / 新关重置棋盘、计时、血量、特效，激活按钮高亮正确。
- 键盘：方向键移动选格、空格循环、Z 撤销。

### 用测试钩子快速验证

```js
__meowdoku.newGame(7, 12345);   // 固定 seed 复现
const sol = __meowdoku.getSolution();
__meowdoku.attempt(Math.floor(sol[0]/7), sol[0]%7); // 正确格 → 落子，hp 不变
__meowdoku.hp();                // 3
// 在非解、非自动排除的空格 attempt → 扣血、不落子
__meowdoku.hp(); __meowdoku.status();   // 观察扣血 / 'lost'
__meowdoku.solveAll();          // 套唯一解 → 通关
__meowdoku.isSolved();          // true
```

## 视觉 QA（桌面 + 手机比例）

- 相邻区域颜色可区分；区域粗边明显强于细格线。
- 小猫深炭剪影在任意区域色上都清楚；冲突红猫醒目。
- 5×5（大格）到 10×10（小格）猫与 ✕ 都保持可识别。
- 通关弹层不遮用时，文字不溢出按钮。
- 手机竖屏整列不超视口、触控键够大。
