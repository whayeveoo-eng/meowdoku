# Meowdoku · 喵咪安家 🐾

🎮 在线试玩：**https://whayeveoo-eng.github.io/meowdoku/**

喵主题逻辑解谜（猫版 LinkedIn「Queens」）。N×N 棋盘被分成 N 个连通的同色区域，给每只猫安一个家：

- 每行、每列、每种颜色 **恰好 1 只猫**；
- 任意两只猫 **不能挨着**（上下左右斜角都不行）；
- 每关 **唯一解、且能纯逻辑一步步推出来**（无需猜）；
- 每关 **3 ❤️**，放错猫扣 1 滴、留红 ✕，归零失败。

## 玩法

- **点格子循环**：空 → ✕（排除标记）→ 🐱（放猫）→ 空。
- **校验放子**：放对落子；放错 → 留红 ✕、扣 1 ❤️、不落子。
- **自动排除**（可开关）：放对一只猫自动 ✕ 掉它的整行/列/九宫格/同色区域。
- 工具：自动叉 / 撤销 / 清空 / 提示 / 新关；六档尺寸 5×5 ~ 10×10。

## 本地运行

纯静态、无构建（仓库根即游戏首页）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```
